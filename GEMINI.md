# База знаний проекта: Паспортизация и ТО оборудования АО «Интергаз Центральная Азия»

> **Инструкция и контекст проекта для Gemini CLI / Google Antigravity**  
> При запуске в этой директории Gemini автоматически считывает данный файл и находится в полном курсе архитектуры, задач и правил.

---

## 1. О проекте и предприятии
* **Заказчик / Предприятие:** АО «Интергаз Центральная Азия» (дочерняя компания АО «НК «QazaqGaz», Казахстан) — единый национальный оператор магистральной транспортировки природного газа.
* **Производственные объекты:**
  - **ЛПУ** — Линейно-производственные управления магистральных газопроводов;
  - **ГРС** — Газораспределительные станции (редуцирование давления, одоризация, учет);
  - **КС** — Компрессорные станции (газоперекачивающие агрегаты ГПА, компрессоры, центробежные нагнетатели).
* **Ключевой принцип бюджетирования:** **ПОЛНОЕ ОТСУТСТВИЕ СУММ И ЦЕН**. В системе нет денег и валют (`₸`, `₽`). Все расчеты ведутся исключительно в физических показателях: *сроки ТО (дни/часы), единицы ЗИП (шт., комплекты, литры), количество открытых дефектов*.

---

## 2. Архитектура системы
1. **Бэкенд:** Python 3.11+ / FastAPI / Uvicorn на защищённом порту **`HTTPS 8443`**.
   - SSL/TLS сертификаты генерируются автоматически модулем `app/ssl_manager.py` со сроком до 365 дней (Safari/iOS совместимо) и поддержкой локальных IP-интерфейсов.
2. **Фронтенд:** Vanilla JS + CSS SPA в индустриальном премиум-стиле **Mind**:
   - Фон `#09090f`, свечение `#7B2FF7 → #4B3BFF → #1E90FF`, акцент `#00F5FF`.
   - Полная автономность: локальные шрифты Geist/Geist Mono, иконки SVG, никаких внешних CDN.
3. **Защищённый QR-контроль (`app/security_qr.py`):**
   - QR-коды шифруются и подписываются алгоритмом HMAC-SHA256 с солью агрегата.
   - Сканируются **ТОЛЬКО внутренней камерой приложения**. Обычные сканеры мобильных телефонов показывают предупреждение и блокируют доступ.
   - Поддерживается одноразовая ротация QR-кода инженером при компрометации.
4. **Документы и автогенерация PDF (`app/pdf_generator.py`):**
   - Официальный паспорт агрегата с крипто-QR кодом;
   - Протоколы технической диагностики и неразрушающего контроля;
   - График планово-предупредительного ремонта (ППР) и ведомость ЗИП;
   - Дефектная ведомость с фиксацией открытых отказов и мероприятий по устранению;
   - Фотоосмотры с визуальной фиксацией дефектов и узлов.

## 3. Интеграция с Microsoft Active Directory (AD / LDAP)
Система работает с корпоративным каталогом пользователей АО «Интергаз Центральная Азия»:
* **Аутентификация:** Keycloak 26 (User Federation по протоколу LDAP/LDAPS) с прямым fallback-модулем `app/ad_auth.py` (через `ldap3`).
* **Серверная учётная запись:** Задается в файле `.env` (`AD_BIND_DN`, `AD_BIND_PASSWORD`) и используется для авторизованного чтения каталога (Read-Only).
* **Сопоставление доменных групп безопасности с ролями:**
  - `GG_ICA_Mechanics` $\rightarrow$ **`admin`** (Главный механик: полный доступ, паспортизация, выпуск QR);
  - `GG_ICA_Engineers` $\rightarrow$ **`engineer`** (Сменный инженер: отметка ТО, фотоосмотры, дефекты);
  - `GG_ICA_Operators` $\rightarrow$ **`operator`** (Дежурный оператор ГРС/КС: просмотр паспортов и графиков).
* **Эндпоинт статуса AD:** `GET /api/auth/ad-status`.
* **Диагностическая утилита:** `python scripts/test_ad_connection.py`.
