# Mind Equip — Локальная база документации, диагностики и ТО оборудования по QR-коду

Одностраничное адаптивное веб-приложение (SPA) для оперативного доступа со **смартфона** в локальной сети (LAN / Wi-Fi) к паспортам оборудования и техническим документам в формате **PDF**, фотофиксации визуального технического состояния, ведения дефектных ведомостей, контроля графиков ТО и планирования бюджета на материалы/ЗИП.

- **Стек:** Python 3.10+ (`venv`), FastAPI, Uvicorn, `cryptography` (X.509 SSL), `fpdf2`, `qrcode`, `Pillow`
- **Адрес и порт:** `https://0.0.0.0:5810`
- **Сертификат:** самоподписанный TLS-сертификат (`certs/cert.pem`), автоматически выпускаемый с привязкой `0.0.0.0`, `127.0.0.1`, `localhost` и активных LAN IPv4-адресов компьютера в `Subject Alternative Name (SAN)`
- **Автономность:** 100% локальная работа без интернета и без внешних CDN; без учётных записей пользователей

---

## Быстрый старт (Windows PowerShell)

```powershell
# 1. Создание и активация обязательного виртуального окружения venv
python -m venv venv
.\venv\Scripts\Activate.ps1

# 2. Установка зависимостей
pip install -r requirements.txt

# 3. Запуск сервера на https://0.0.0.0:5810
python run.py
```

При старте в консоль будут выведены ссылки вида `https://192.168.x.x:5810` для подключения со смартфона в той же сети Wi-Fi.

> **Примечание по брандмауэру Windows:** если смартфон в сети Wi-Fi не открывает страницу, разрешите входящие подключения на порт **TCP `5810`** (в PowerShell от имени Администратора):
> ```powershell
> New-NetFirewallRule -DisplayName "QR Equipment Docs HTTPS 5810" -Direction Inbound -Protocol TCP -LocalPort 5810 -Action Allow
> ```

## Подключение со смартфона

1. Подключите смартфон к той же локальной сети Wi-Fi, что и компьютер-сервер.
2. Откройте в мобильном браузере (Safari на iOS / Chrome на Android) адрес `https://<LAN_IP>:5810`, указанный в консоли запуска.
3. На экране предупреждения о самоподписанном сертификате один раз нажмите **«Дополнительно» → «Перейти на сайт»** (в Safari: **«Показать подробности» → «Посетить этот веб-сайт»**).
4. Нажмите **«Сканировать QR-код»**, разрешите доступ к камере и наведите объектив на QR-код оборудования.

## Локальное хранение данных (`./documents/`)

Все файлы хранятся на том же компьютере в папке `documents/`:
- `documents/registry.json` — реестр карточек оборудования, графиков ТО, норм ТМЦ/ЗИП, дефектов и истории осмотров;
- `documents/<equipment_id>/passport/` — паспорт оборудования (PDF);
- `documents/<equipment_id>/diagnostics/` — документы диагностики (PDF, при наличии);
- `documents/<equipment_id>/schedule/` — графики и регламенты ТО (PDF);
- `documents/<equipment_id>/defects/` — дефектные ведомости (PDF);
- `documents/<equipment_id>/photos/` — загруженные со смартфона фотографии визуального состояния.
