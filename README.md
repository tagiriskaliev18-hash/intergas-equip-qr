# Интергаз Центральная Азия — Локальная база документации, диагностики и ТО оборудования (ЛПУ, ГРС, КС)

Одностраничное адаптивное веб-приложение (SPA) для оперативного доступа со **смартфона** в локальной сети (LAN / Wi-Fi) к паспортам оборудования и техническим документам в формате **PDF**, фотофиксации визуального технического состояния, ведения дефектных ведомостей, контроля графиков регламентных работ и потребности в запасных частях/материалах (ЗИП в физ. единицах без денежных сумм) на объектах **АО «Интергаз Центральная Азия»** (ЛПУ магистральных газопроводов, компрессорные станции КС, газораспределительные станции ГРС), аутентификации через **Keycloak** и генерации **уникальных закрытых QR-кодов**, которые распознаются только камерой данного приложения.

- **Заказчик/Контекст:** АО «Интергаз Центральная Азия» (Казахстан, группа QazaqGaz)
- **Учёт и контроль:** Инженерно-эксплуатационный (сроки ТО, статус узлов, потребность в ЗИП в шт./л/компл., дефекты без денежных сумм)
- **Стек:** Python 3.10+ (`venv`), FastAPI, Uvicorn, Keycloak 26.0.7 (OpenJDK 17), `cryptography` (X.509 SSL SAN), `PyJWT`, `fpdf2`, `qrcode`, `Pillow`
- **Адрес и порт:** `https://0.0.0.0:8443` (настраиваемый параметр запуска)
- **Аутентификация (IAM):** Keycloak OIDC (Realm: `mind-equip`, Client: `mind-equip-app`) с ролями `admin`, `engineer`, `operator` + автономный fallback-режим
- **Закрытый криптографический QR:** полезная нагрузка `MINDEQUIP:v2:<equipment_id>:<hmac_token>` не является веб-ссылкой; стандартная камера iOS/Android её не открывает. Камера приложения Mind Equip валидирует токен на сервере и переходит к агрегату.
- **Сертификат:** самоподписанный TLS-сертификат (`certs/cert.pem`), автоматически выпускаемый с привязкой `0.0.0.0`, `127.0.0.1`, `localhost` и активных LAN IPv4-адресов компьютера в `Subject Alternative Name (SAN)`
- **Автономность:** 100% локальная работа без интернета и без внешних CDN (Zero CDN)

## Быстрый старт (Windows PowerShell)

```powershell
# 1. Запуск сервера Keycloak (порт 8080)
powershell.exe -ExecutionPolicy Bypass -File "scripts\start_keycloak.ps1"

# 2. Активация виртуального окружения Python
.\venv\Scripts\Activate.ps1

# 3. Запуск основного веб-приложения на порту 8443 (HTTPS)
python run.py
```

При старте в консоль выводятся защищённые адреса для смартфона: `https://<LAN_IP>:8443` и ссылка на Keycloak.

> **Настройка брандмауэра Windows:** если смартфон в сети Wi-Fi не открывает страницу, разрешите входящие подключения на порт **TCP `8443`** (в PowerShell от имени Администратора):
> ```powershell
> New-NetFirewallRule -DisplayName "Mind Equip HTTPS 8443" -Direction Inbound -Protocol TCP -LocalPort 8443 -Action Allow
> ```

## Закрытый QR-код (Proprietary Closed Loop)

1. **Генерация:** в карточке агрегата формируется этикетка с полезной нагрузкой:
   ```text
   MINDEQUIP:v2:<equipment_id>:<HMAC_TOKEN_16>
   ```
2. **Сканирование сторонними камерами:** стандартные приложения камеры iOS, Google Lens или generic QR-сканеры видят этот код как сырой текст без URL-схемы, поэтому они не могут перейти по ссылке и открыть страницу.
3. **Сканирование приложением Mind Equip:** встроенный видеосканер распознаёт закрытый префикс `MINDEQUIP:`, отправляет токен на проверку подлинности (`POST /api/verify-qr-token`), выводит верификационный бейдж с инвентарным номером и переходит к карточке агрегата.
4. **Ротация токенов:** в карточке оборудования инженер или администратор может нажать **«Перевыпустить токен»** (`POST /api/equipment/{id}/rotate-qr`). Старый физический QR-код на агрегате немедленно перестаёт работать.

## Подключение со смартфона

1. Подключите смартфон к той же локальной сети Wi-Fi, что и компьютер-сервер.
2. Откройте в мобильном браузере (Safari на iOS / Chrome на Android) адрес `https://<LAN_IP>:8443`, указанный в консоли запуска.
3. На экране предупреждения о самоподписанном сертификате один раз нажмите **«Дополнительно» → «Перейти на сайт»** (в Safari: **«Показать подробности» → «Посетить этот веб-сайт»**).
4. Войдите под учётной записью (`admin`, `engineer` или `operator`).
5. Нажмите **«Сканировать QR-код»**, разрешите доступ к камере и наведите объектив на закрытый QR-код оборудования.

## Локальное хранение данных (`./documents/`)

Все файлы хранятся на том же компьютере в папке `documents/`:
- `documents/registry.json` — реестр карточек оборудования, графиков ТО, норм ТМЦ/ЗИП, дефектов и истории осмотров;
- `documents/security.json` — криптографический реестр токенов защищённых QR-кодов оборудования;
- `documents/<equipment_id>/passport/` — паспорт оборудования (PDF);
- `documents/<equipment_id>/diagnostics/` — документы диагностики (PDF, при наличии);
- `documents/<equipment_id>/schedule/` — графики и регламенты ТО (PDF);
- `documents/<equipment_id>/defects/` — дефектные ведомости (PDF);
- `documents/<equipment_id>/photos/` — загруженные со смартфона фотографии визуального состояния.
