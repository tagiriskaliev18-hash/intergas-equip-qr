# Дополненный промпт для генерации ТЗ (Интергаз Центральная Азия · ЛПУ, ГРС, КС · Тенге ₸)

Ниже приведён доработанный и расширенный текст промпта (с учётом всех отраслевых, эксплуатационных, сетевых, криптографических и производственных требований):

```markdown
Составь подробное техническое задание (ТЗ) в формате Markdown (.md) для разработки следующего веб-приложения:

1. Концепция, организация и целевые устройства:
- Заказчик/Контекст: АО «Интергаз Центральная Азия» (Казахстан) — национальный оператор магистральных газопроводов. Эксплуатация оборудования на объектах ЛПУ (линейно-производственные управления), ГРС (газораспределительные станции) и КС (компрессорные станции).
- Валюта всех расчётов, смет, дефектных ведомостей и бюджетных заявок: казахстанский тенге (₸ / KZT).
- Одностраничное веб-приложение (SPA) на точке входа с адаптивным экраном (mobile-first под смартфоны iOS/Android 390×844 и 360×800, а также планшеты и ПК 1440×900).
- Основное устройство эксплуатации — смартфон сотрудника в локальной сети Wi-Fi технологического объекта (работа в изолированном локальном контуре, zero CDN).
- Приложение является единой точкой входа в локальную базу эксплуатационной документации оборудования (в формате PDF), контроля технического состояния и планирования ТО.
- Учётные записи и аутентификация через Keycloak: вход по протоколу OIDC (OpenID Connect / Authorization Code Flow) и сессионным JWT cookie. Ролевая модель: admin (Главный механик), engineer (Инженер ТО), operator (Оператор / Наблюдатель).

2. Сценарий уникального закрытого QR-сканирования:
- Приложение генерирует уникальный криптографический QR-код оборудования (формат полезной нагрузки MINDEQUIP:v2:<id>:<hmac_token>), который можно отсканировать ТОЛЬКО из встроенной видеокамеры приложения.
- Сторонние сканеры, стандартная камера iPhone или Android не открывают сайт и не переходят по ссылке, отображая немаршрутизируемую текстовую строку.
- На главном экране расположена кнопка «Сканировать QR-код». При нажатии открывается камера смартфона (тыловая камера environment, встроенный видеопоток playsinline).
- Приложение распознаёт закрытый QR-код, выполняет проверку подлинности токена на сервере, отображает статус верификации и открывает карточку агрегата.
- Возможность перевыпуска (ротации) криптографического QR-токена инженером или администратором при необходимости скомпрометировать старую наклейку.

3. Документация и функционал карточки оборудования (всё хранится локально на том же компьютере в папке `./documents/<equipment_id>/`):
- Паспорт оборудования в формате PDF (скачивание по прямой ссылке + загрузка/обновление).
- Документы диагностики в формате PDF — при наличии (вибродиагностика ГПА, тепловизионный контроль, ревизия клапанов и ПГП; если документов нет — корректная индикация отсутствия с возможностью прикрепить PDF позже).
- Графики ТО (периодичность, даты последнего и следующего ТО, отметка о выполнении ТО, хранение и скачивание PDF-графиков).
- Материалы и ЗИП для ТО (перечень расходников и запчастей, количество, единицы измерения, наличие на складе, стоимость материалов и работ в тенге ₸).
- Уведомления о приближении ТО и бюджетировании: автоматическое предупреждение за N дней до наступления ТО (и при просрочке) с напоминанием заблаговременно предусмотреть рассчитанную сумму в тенге (₸) на закупку материалов и работы в бюджете (+ выгрузка бюджетной заявки в PDF).
- Дефектные ведомости: хранение и скачивание готовых PDF дефектных ведомостей, ведение перечня выявленных дефектов и автоматическая генерация печатной дефектной ведомости в формате PDF с оценкой затрат в тенге (₸).
- Визуальная оценка технического состояния: загрузка фотографий оборудования прямо со смартфона (камера/галерея) с фиксацией даты, комментария и статуса техсостояния («Исправно», «Требует внимания», «Критический дефект») в локальную фотоленту агрегата.
- Генерация защищённых QR-этикеток (стикеров для печати) с закрытым токеном.

4. Стек, сеть и безопасность:
- Основной стек: Python 3.10+ (FastAPI + Uvicorn + cryptography + PyJWT + fpdf2 + qrcode + Pillow).
- Сервер аутентификации: Keycloak 26 (realm: mind-equip, OpenID Connect).
- Обязательно создание и использование виртуального окружения `venv`.
- TCP-порт: `8443` (или любой настраиваемый через аргументы/env).
- При запуске приложение обязательно привязывается к адресу `0.0.0.0`.
- Автоматическое создание самоподписанного TLS-сертификата (HTTPS обязателен для доступа мобильного браузера к камере): привязка сертификата в Subject Alternative Name (SAN) на адрес `0.0.0.0`, `127.0.0.1`, `localhost` и активные локальные IPv4-адреса сервера; срок действия сертификата <= 365 дней (для совместимости с iOS Safari).
- Защита от Path Traversal при скачивании/загрузке локальных файлов, проверка форматов PDF/изображений, поддержка кириллических имён файлов (RFC 5987) и защита от XSS при выводе данных QR-кода.
```
